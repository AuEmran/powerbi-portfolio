# Dataset Documentation

All CSV files under `datasets/synthetic/` are **fictional, generated data** created for this portfolio. They preserve the field structure and relationships of the real dashboards they represent but contain no real business, government, or employer records.

| File | Used by | Description |
|---|---|---|
| `laptop_assets_synthetic.csv` | Laptop Asset Lifecycle | Fictional laptop asset register: tag, model, purchase/warranty dates, status |
| `laptop_requests_synthetic.csv` | Laptop Asset Lifecycle | Fictional new-starter/replacement request log |
| `mobile_services_synthetic.csv` | Mobile Fleet Management | Fictional mobile service/billing register with usage and registration flags |
| `business_case_synthetic.csv` | Business Case & Mediation Mapping | Fictional case/mediation-application log by postcode and industry |
| `lga_business_counts_synthetic.csv` | Business Case & Mediation Mapping | Fictional total registered business counts per LGA/industry |
| `business_risk_mapping_synthetic.csv` | Business Risk Mapping (Bushfire/Flood) | Fictional ABN business register with hazard-zone classification |

## Portfolio-wide disclaimer
No file in this repository contains real employee names, government records, customer data, ABNs, addresses, or financial figures. All figures are illustrative and generated solely to demonstrate the data model and analytical approach behind each dashboard.
